# Localization Testing Checklist

- [ ] UI text uses the selected language consistently
- [ ] Text does not mix visually similar characters from different scripts unintentionally
- [ ] Translations preserve meaning and context
- [ ] Dates, times, numbers, currency, and units match the locale
- [ ] Pluralization and grammatical forms are correct
- [ ] Text fits controls without truncation, overlap, or clipping
- [ ] Right-to-left layouts behave correctly where supported
- [ ] Search, sorting, copying, and input work with supported scripts
- [ ] Error, empty, loading, and notification states are localized
- [ ] User-generated content is not incorrectly translated or normalized
