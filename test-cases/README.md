# Test Cases

Detailed test cases are grouped by product area or feature. Each case should be clear enough for another tester to execute without additional explanation.

A test case includes:

- unique ID and concise title;
- purpose and priority;
- preconditions and test data;
- numbered actions with expected results;
- execution status and notes.

```text
test-cases/
└── product-or-feature/
    ├── README.md
    └── PRODUCT-TC-001-short-title.md
```
